### Install
1. Open **[Releases → Latest](https://github.com/robertasouzaxd-gif/long-video-editor-releases/releases/latest)** and download **`Long-Video-Editor-Setup-x.x.x.exe`**.
2. Run the installer (if Windows SmartScreen appears: **More info → Run anyway**).
3. Open **Long Video Editor**, create your account and enter your **License Key**.
4. The first launch downloads the AI components once (~10 GB).

### Updates
Updates install automatically — the app shows **"Restart to update"** when a new version is ready.

### License
A valid license key is required. One key works on one PC. Contact your administrator for a key or renewal.
